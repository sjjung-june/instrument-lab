# APT educational module

공통 3D 제어: 시점 초기화·선택 강조·분해 보기. 선택은 녹색, 관련 부품은 황색, 나머지는 반투명입니다. 재생 속도는 장비별 0.1/0.25/0.5/1/2×, 기본 0.25×입니다. 문서의 취득 시간은 1× 기준 가상 시간이며 기본 재생에서는 실제 대기 시간이 약 4배입니다. 속도 변경은 데이터·측정 조건을 유지합니다. 공통 구현은 프로젝트 루트의 src/shared/에 있으므로 전체 소스를 함께 유지하세요.

통합 장비 목록의 APT를 선택합니다. `npm run build:apt`로 `public/apt/`에 빌드하며 전체 빌드·테스트에도 포함됩니다. 공통 시각 스타일은 `spectroscopy-source/src/`의 CSS를 재사용하므로 프로젝트 전체 소스를 함께 유지하세요.

## 동작
- 8개 메쉬 파트, 회전·확대·직접 클릭, 선택 외 파트 감광, 분해 보기, 4개 증상별 유지보수 가이드.
- Laser-pulsed / Voltage-pulsed: 레이저 보조 또는 전압 펄스의 신호 경로를 구분합니다. 두 모드의 성능 차이는 계산하지 않습니다.
- 하나의 취득 버퍼로 질량 스펙트럼, 검출 XY 히트맵, 독립 회전·확대 가능한 3D 점군을 누적합니다. Si/Cu/B 표시 필터는 데이터와 취득 진행을 보존합니다.
- 4,096개 단일 이온 이벤트 / 12초 애니메이션. 실제 펄스율·검출률이 아닙니다. 일시정지/재개, 조건 변경 초기화, 문서가 숨겨질 때 일시정지, 장비 탭 전환 시 상태 유지를 지원합니다.
- 가상 Cu-rich 캡(0–8 nm), Si 기지, B-rich 층(중심 19 nm), 명목 반경 8 nm / 깊이 30 nm. 실제 HBM 구조·측정 데이터가 아니며, APT는 별도의 니들형 시료 준비가 필요합니다.

## 계산과 한계
직선 길이 L=0.10 m, 유효 가속전압 |V|=2–8 kV, 균일 전하 상태 z=1 또는 2를 가정합니다. t=L√[(m/z)u/(2e|V|)]에서 TOF(ns)를 만들고 같은 이상식을 역변환해 m/z(Da/e)를 얻습니다. 모든 이온의 2+ 설정은 전하 효과를 보여주는 가정이지 실제 전하 상태 예측이 아닙니다. 전압 펄스 파형·시간 영점·에너지 분산·열 꼬리·분자 이온·질량 중첩·다중 히트·검출 효율·교정·정량은 계산하지 않습니다.

검출 XY는 정규화 원판 좌표이며 고정 선형 역투영 x=8·hitX, y=8·hitY와 이벤트 순서 z=30·index/(4096−1)로 점군을 생성합니다. 실제 팁 형상·원자 부피·영상 압축·국소 배율 기반 물리 재구성이 아닙니다. 이온종과 동위원소 비율은 합성 데이터 라벨로, 물질 동정·조성 정량을 수행하지 않습니다. 3D 메쉬·팁 소모·펄스·이온 경로는 확대된 개념 표현입니다.

CSV는 취득 이벤트만 저장합니다. 열은 이벤트 번호, 합성 원소, 가정 전하, m/z(Da/e), TOF(ns), 정규화 검출 XY, 명목 XYZ(nm), CSV 규칙으로 인용한 JSON 메타데이터입니다. 초기화·조건 변경·완료 후 재취득은 새 가상 니들입니다. 실제 전계 증발은 파괴적이며 복원되지 않습니다.

고전압·레이저·초고진공·저온 장비의 일반적 점검 방향만 제공합니다. 실장비 설정·제조사 절차·교정·안전 교육을 대체하지 않습니다.
