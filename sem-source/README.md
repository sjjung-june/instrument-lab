# SEM Lab

기존 Instrument Lab의 SEM 탭에서 사용합니다. SE/BSE 전환, 9개 메쉬 파트 탐색, 회전·확대·선택 강조·분해 보기, 64×64 래스터 취득, 일시정지·재개·초기화, 초점 흐림, CSV 내보내기 및 4개 증상 가이드를 제공합니다.

`npm run build:sem`은 이 소스를 `public/sem/`으로 빌드합니다. 통합 빌드는 루트의 `npm run build`, 테스트는 `npm test`입니다. 메인 앱은 정적 iframe을 사용하므로 수정 후 재빌드하고 새로고침하세요.

## 교육용 가정

- SEM 주사는 전자빔의 XY 편향이며 시료 스테이지는 고정입니다. 같은 `heightAt` 함수를 3D 메쉬와 영상에 사용하고, 마지막 취득 픽셀을 3D 스폿에 대응시킵니다.
- SE는 합성 표면 기울기·텍스처, BSE는 상대 조성 두 영역과 약한 형상 기여를 사용합니다. 밝은 원형 영역의 상대값은 .88, 배경 .48, 어두운 원형 영역 .22입니다. 원소명·실제 조성·실제 길이·절대 신호를 의미하지 않습니다.
- SE 측면 검출과 BSE 환형 검출은 일반화 기하입니다. 굵은 선은 신호 흐름 안내이며 전자 궤적·전기장 해석이 아닙니다. 분해 보기에서는 신호를 숨깁니다.
- 8초 단방향 래스터, 줄 복귀 시간 제외. 초점 흐림은 9점 공간 평균이며 전자광학적 프로브 계산이 아닙니다. 검출 모드·흐림 변경 시 취득을 초기화해 서로 다른 조건이 한 프레임에 섞이지 않게 합니다.
- 밝기는 a.u.이며 실제 SEM의 가속전압·진공·대전·비점수차·원소 분석을 재현하지 않습니다. 관련 증상은 점검 가이드이며 고장 주입 시뮬레이션은 아닙니다.
- 탭을 전환한 iframe 세션은 유지됩니다. 브라우저 문서가 숨겨지면 SEM 취득은 일시정지합니다. 실제 정비는 제조사 매뉴얼과 교육받은 담당자 절차를 우선합니다.
