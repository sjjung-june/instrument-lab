XRD / XRR 교육 모델

Out-of-plane은 대칭 θ–2θ 기하, In-plane은 작은 입출사각(0.6°)과 면내 회전, XRR은 낮은 각도의 정반사 기하로 일반화했습니다. 실제 구동 축과 광학계는 기종마다 다릅니다.

XRD 피크 위치는 Bragg 식을 사용하지만 상대 세기와 피크 폭은 합성입니다. XRR은 고정 임계각 0.22°의 감쇠 포락선과 qz·두께 간섭, 거칠기 감쇠를 조합한 개념식입니다. Parratt 피팅, 다층 반사, 밀도 분석 또는 실제 시료의 두께 추정은 제공하지 않습니다.

모드 또는 파라미터를 변경하면 기존 데이터가 초기화됩니다. 분해 보기에서는 빔을 숨깁니다. 실제 X선 차폐와 인터록을 우회하지 마세요.
